# Quick Start

Use this guide to set up Budget Planner for the first time.

1. Open `Settings` and review planner settings.
2. Set currency, pay period anchor date, pay frequency, projection range, and monthly bill assignment rule.
3. Export your first backup from `Settings > Data Management` and keep the file somewhere safe.
4. Open `Accounts` and enter starting balances.
5. Open `Scheduled Items` and add recurring income, bills, subscriptions, transfers, debt payments, and savings items.
6. Open `Savings Buckets` and create buckets for planned savings goals.
7. Open `Categories` and adjust category names if needed.
8. Open `Budgets` and create monthly category targets.
9. Review `Dashboard` for projected balances and alerts.
10. Review `Reports` for summaries, charts, trends, print, and report CSV export.
11. Export backups regularly from `Settings > Data Management`.

Tip: Always export a backup before clearing browser data, switching browsers, switching devices, importing another backup, or resetting local data.

## Install The App

Desktop browser:

1. Open the app URL.
2. Look for the install icon in the address bar.
3. Choose install.
4. Open Budget Planner from the desktop, dock, start menu, or app launcher.

Mobile browser:

1. Open the app URL.
2. Open the browser menu.
3. Choose `Add to Home Screen` or `Install App`.
4. Open Budget Planner from the home screen.

Exact wording depends on browser and device. Export a backup before installing
or uninstalling the PWA, clearing site data, switching browsers, or switching
devices. Store backup files somewhere safe outside the browser.
