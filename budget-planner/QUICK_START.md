# Quick Start

Use this guide to set up Budget Planner for the first time.

The app starts with fictional demo data so you can explore features right away.
To start fresh, go to `Settings > Data Management > Factory Reset to Empty App`.
To restore the public demo later, use `Reset to Demo Data`.

On first run, Dashboard shows three choices:

- `Explore Demo Data` keeps the fictional sample records and dismisses onboarding.
- `Start Empty` takes you to Settings so you can use the typed empty reset.
- `Import Backup` takes you to Settings so you can use the existing safe import flow.

1. Install the PWA if you want an app-like shortcut.
2. Export your first backup from `Settings > Data Management` and keep the file somewhere safe.
3. Open `Settings` and review planner settings.
4. Set currency, pay period anchor date, pay frequency, projection range, and monthly bill assignment rule.
5. Open `Accounts` and enter starting balances.
6. Open `Scheduled Items` and add recurring income, bills, subscriptions, transfers, debt payments, and savings items.
7. Open `Savings Buckets` and create buckets for planned savings goals.
8. Open `Categories` and adjust category names if needed.
9. Open `Budgets` and create monthly category targets.
10. Review `Dashboard` for projected balances and alerts.
11. Review `Reports` for summaries, charts, trends, print, and report CSV export.
12. Open `Help` anytime for guidance on local data, backups, setup, and PWA install.
13. Export backups regularly from `Settings > Data Management`.

Tip: Always export a backup before clearing browser data, switching browsers, switching devices, importing another backup, or resetting local data.

## Install The App

Desktop browser:

1. Open the app URL.
2. Look for the install icon in the address bar.
3. Choose install.
4. Open Budget Planner from the desktop, dock, start menu, or app launcher.

Mobile browser:

1. Open the app URL.
2. Open the browser menu.
3. Choose `Add to Home Screen` or `Install App`.
4. Open Budget Planner from the home screen.

Exact wording depends on browser and device. Export a backup before installing
or uninstalling the PWA, clearing site data, switching browsers, or switching
devices. Store backup files somewhere safe outside the browser.
