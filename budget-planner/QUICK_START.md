# Quick Start

Use this guide to set up Budget Planner for the first time.

1. Open `Settings` and review planner settings.
2. Set currency, pay period anchor date, pay frequency, projection range, and monthly bill assignment rule.
3. Open `Accounts` and enter starting balances.
4. Open `Scheduled Items` and add recurring income, bills, subscriptions, transfers, debt payments, and savings items.
5. Open `Savings Buckets` and create buckets for planned savings goals.
6. Open `Categories` and adjust category names if needed.
7. Open `Budgets` and create monthly category targets.
8. Review `Dashboard` for projected balances and alerts.
9. Review `Reports` for summaries, charts, trends, print, and report CSV export.
10. Export backups regularly from `Settings > Data Management`.

Tip: Always export a backup before clearing browser data, switching browsers, switching devices, importing another backup, or resetting local data.
